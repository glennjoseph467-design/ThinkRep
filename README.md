# ThinkRep

Daily cognitive training and assessment platform. Train your independent thinking through timed challenges, track your progress, and prove it with a score.

## Tech Stack
- Frontend: React 18 + Vite + React Router
- Backend: Express.js + JWT auth
- Database: SQLite (better-sqlite3)
- Styling: Custom CSS (dark theme, mobile-first)

## Setup
npm run setup
npm run dev

## Production
npm run build
npm start
